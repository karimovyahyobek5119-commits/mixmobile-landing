# Mix Mobile — Landing Page Concept

A responsive landing page I designed and built as an unsolicited concept for Mix Mobile, a local mobile phone store in Uzbekistan, to offer them a modern web presence.

**Live demo:** https://mixmobile-demo.netlify.app

> This is an independent concept project and is not an official Mix Mobile website.

## Features
- Sticky header with smooth scrolling to page sections
- Hero section with key store stats and call-to-action buttons
- Trust strip and services cards (trade-in, delivery, 3-day warranty)
- Contact section with phone numbers, social links and store details
- Fully responsive layout for mobile, tablet and desktop
- Built from scratch without frameworks
